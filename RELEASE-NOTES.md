## Palettes v0.7.1

A quick follow-up bugfix release for Palettes v0.7.0, the DaylightUI plugin for World of Warcraft: Forever.

### Fixed
- **My Presets delete button:** Fixed an issue where hovering the `x` delete button on a saved **My Presets** slot caused the tooltip to flicker and prevented clicks from deleting the preset. Populated slots now keep the delete button steadily visible, highlight it on hover, and cleanly remove the saved preset (reverting any staged preview of that slot).

### Install or update
1. You need DaylightUI installed first.
2. Download **Palettes-v0.7.1.zip** below.
3. Unzip it into `Interface/AddOns`, replacing your old `Palettes` folder.
4. In game, type `/reload`.

Found a bug? [Open an issue](https://github.com/odd-brew/daylight-palettes/issues/new/choose). Full details are in the [README](https://github.com/odd-brew/daylight-palettes#readme).
