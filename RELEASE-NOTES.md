## Palettes v0.4.1

Page touch-ups for Plugins > Palettes, for the DaylightUI plugin for World of Warcraft: Forever.

### Changed
- The Themes tab is now Presets.
- Clicking a row picks it. Apply commits it.
- A picked row is easier to read.
- Game Menu buttons restyle on Apply.
- After a real change, Apply, Custom Save, `/palettes`, `/looks`, and Appearance picks ask "Reload to finish applying your changes?" Reload now reloads. Later dismisses. The prompt waits until combat ends.
- Copy and layout fixes.

### Install or update
1. You need DaylightUI installed first.
2. Download **Palettes-v0.4.1.zip** below.
3. Unzip it into `Interface/AddOns`, replacing your old `Palettes` folder.
4. If you had Looks installed, turn it off or remove its folder.
5. In game, type `/reload`.

Found a bug? [Open an issue](https://github.com/odd-brew/daylight-palettes/issues/new/choose). Full details are in the [README](https://github.com/odd-brew/daylight-palettes#readme).
